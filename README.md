## Key Features

- **Vendor Discovery & Multi-Criteria Filtering:** Real-time search by vendor name or city combined with filters for Category (*Venues, Photographers, Caterers, Florists, Makeup & Styling, DJs, Planners*), Location, Maximum Budget (`₹`), and Minimum Rating.
- **Vendor Profiles & Portfolios:** Interactive detail modals displaying vendor descriptions, portfolio highlights, transparent service packages, and verified client reviews.
- **Interactive Booking System:** Date-validated package reservation workflow generating unique booking reference IDs (`BK-XXXXX`) persisted via `localStorage`.
- **Reviews & Ratings System:** Dynamic review submission form allowing couples to rate vendors (1–5 stars) and publish feedback instantly.
- **Dual Marketplace Dashboards:**
  - **User (Couple) Dashboard:** Tracks active bookings, total estimated wedding budget, and saved wishlist/favorites.
  - **Vendor Dashboard:** Enables service providers to publish new vendor listings and monitor incoming client booking requests.
- **Bonus Enhancements:** Wishlist/Favorites toggle, Dark Mode theme switcher, and full mobile responsiveness with a collapsible hamburger menu.


## Tech Stack & Design System

- **Frontend:** Semantic HTML5, CSS3 (Grid, Flexbox, CSS Custom Properties, Media Queries), ES6+ JavaScript
- **Data Storage:** Client-side JavaScript arrays/objects with `localStorage` persistence (no external database required)
- **Color Palette:** Primary Purple (`#8B5CF6`), Surface White (`#FFFFFF`), Light Purple (`#EDE7FF`)
